# Tiny-Tale
# TinyLoRA на малых моделях: зависимость эффективности от числа параметров

Воспроизведение и расширение метода из статьи  
**"Learning to Reason in 13 Parameters"** (Morris et al., FAIR at Meta, 2026)  
[arxiv 2602.04118](https://arxiv.org/abs/2602.04118)

## Идея

Оригинальная статья показала: модель Qwen2.5-7B можно улучшить на задачах математики,
обучив всего **13 параметров** через RL (GRPO). Мы проверяем — работает ли это на
моделях меньшего размера, и как эффективность зависит от числа параметров модели.

Дополнительно сравним два поколения — Qwen3 и Qwen3.5 — при схожих размерах.

## Модели в эксперименте

| Модель | Параметров | Поколение | Размер bf16 | Где скачать |

## Запуск

### 1. Скачать модель вручную
Зайти на HuggingFace → Files and versions → скачать все файлы в соответствующую папку,
например `models/Qwen3-0.6B/`

### 2. Тестовый прогон (~20-40 минут)
Проверяет что всё работает корректно, не оценивает итоговое качество:
```bash
python train.py --config configs/qwen3-0.6b.json --test_run
```

### 3. Полное обучение
```bash
python train.py --config configs/qwen3-0.6b.json
```

### 4. Оценка
```bash
python evaluate.py --checkpoint ./results/Qwen3-0.6B/tinylora_v.pt
```

## Результаты экспериментов

Оценка проводилась на 100 задачах тестовой выборки **GSM8K** после обучения методом GRPO (500 задач, 1 эпоха, `proj_dim = 13` обучаемых параметров, `rank = 1`):

| Модель | Архитектура | Параметры | Learning Rate | Baseline | TinyLoRA | Прирост (Δ) |
|---|---|---|---|---|---|---|
| **Qwen3-0.6B** | Трансформер | 0.6B | `1e-5` | 55% | 58% | **+3%** |
| **Qwen3.5-0.8B** | Гибрид (DeltaNet) | 0.8B | `1e-4` | 37% | 37% | **0%** |
| **Qwen3-1.7B** | Трансформер | 1.7B | `1e-4` | 78% | 80% | **+2%** |
| **Qwen3.5-2B** | Гибрид (DeltaNet) | 2B | `1e-4` | 55% | 58% | **+3%** |

### Ключевые выводы

1. **TinyLoRA работает на малых моделях, но уступает масштабу 7B:** на моделях 0.6B–2B прирост составляет **+2–3%** (против +15% на 7B в оригинальной работе Morris et al., 2026), что подтверждает зависимость эффективности метода от ёмкости базовой модели.
2. **Существует нижняя граница применимости:** сравнение двух гибридных моделей одного поколения (`Qwen3.5-0.8B` и `Qwen3.5-2B`) показывает, что сама архитектура DeltaNet не блокирует обучение (`2B` даёт +3%), но при низком базовом качестве модели (`37%` у `0.8B`) адаптации 13 параметров недостаточно для сдвига точности.
3. **Масштабирование `learning rate` с глубиной сети:** для 0.6B оптимальным оказался шаг `1e-5`, тогда как более глубоким моделям (1.7B и 2B) требуется `1e-4` для компенсации затухания градиентного сигнала через замороженные слои.

### Инженерные оптимизации и стенд

* **Перенос SVD-буферов на GPU (`register_buffer`):** вычисление $\Delta W$ целиком на видеокарте без пересылок CPU ↔ GPU сократило время одного шага обучения со **114 секунд до 3 секунд**.
* **Кастомный `SaveVCallback`:** сохранение только разделяемого вектора $v$ (26 байт) вместо дублирования общих тензоров.
* **Аппаратный стенд и скорость:** NVIDIA GeForce RTX 4050 Laptop (6 GB VRAM), Intel Core i5-12500H, 64 GB RAM; скорость пакетной генерации составила **46–104 tok/s**, время одного шага GRPO — **35–85 секунд** в зависимости от модели.
